# ÜMIT

Flutter қосымшасы: донорлық, еріктілік және қайырымдылық шаралары.

## Іске қосу

```sh
flutter pub get
flutter run
flutter test
```

VS Code-та Run and Debug → `ÜMIT — Web (Release)` → F5.
Бұл конфигурация `lib/main.dart` файлын іске қосып, сайтты Microsoft Edge браузерінде ашады.
Тұрақты мекенжай: `http://127.0.0.1:59164`. Бірінші release жинағы бірнеше минут алуы мүмкін; браузер жинақ аяқталғаннан кейін ашылады.
Stop басылғанда сервер де тоқтайды. Қайта ашу үшін F5 басыңыз. Екі конфигурацияны қатар іске қоспаңыз: екеуі бір портты қолданады.
Терминалдан іске қосу: `flutter run -d edge --release --web-hostname=127.0.0.1 --web-port=59164`.
Кодты жөндеу үшін бөлек `ÜMIT — Debug` конфигурациясы бар.
Басты беттің ұзын тізімі экранға жақындаған бөлімдерді ғана құрады.

Montserrat қарпі assets/fonts ішінде сақталған, интернетсіз жүктеледі. Оның OFL лицензиясы сол қалтада.

## Демо әкімші

Авторизациядағы «Демо әкімші» батырмасы кіру өрістерін толтырады:

- Пошта: admin@umit.kz
- Құпиясөз: UmitAdmin2026!

Қарапайым тіркелу тек пайдаланушы рөлін береді. Пайдаланушы экраннан немесе күй қоймасынан әкімші әрекеттерін орындай алмайды.

## Мүмкіндіктер

Әкімші: статистика, шара қосу/өңдеу, күн мен уақыт, орын лимиті, жариялау/жасыру, өтінімі жоқ шараны өшіру, өтінімді мақұлдау/қабылдамау, қатысуды растау, пайдаланушыларды іздеу және бұғаттау, хабарлама жіберу, CSV есебін көшіру.

Пайдаланушы: іздеу және сүзу, сақтау, өтінім беру/бас тарту, мәртебені бақылау, мақұлданған қатысу билетін көшіру, хабарламалар, «Менің үлесім» белестері. Қонақ шараларды қарай алады; өтінім беру үшін тіркелу керек.

## Тексеру сценарийі

1. Жаңа пайдаланушы тіркеп, кіріңіз; шараға өтінім жіберіңіз.
2. Шығып, демо әкімшімен кіріңіз. «Өтінімдер» бөлімінде өтінімді мақұлдаңыз.
3. Пайдаланушымен қайта кіріңіз: кабинетте мәртебе мен билет, мәзірде хабарлама көрінеді.
4. Әкімші «Қатысқанын белгілеу» таңдағаннан кейін «Менің үлесім» есебі жаңарады.

## Код құрылымы

- lib/main.dart — іске қосу және жергілікті деректерді жүктеу.
- lib/app.dart — қосымша мен тақырыпты қосу.
- lib/core/theme.dart — түстер, қаріп, тақырып.
- lib/models/models.dart — аккаунт, шара, өтінім, хабарлама модельдері.
- lib/state/app_store.dart — рөл тексеру, өтінім ауысулары және сақтау.
- lib/data/ — бастапқы шаралар мен ақпараттық мәтіндер.
- lib/screens/auth/ — авторизация және тіркелу.
- lib/screens/admin/ — басқару панелі және шара редакторы.
- lib/screens/home/ — пайдаланушы экраны және бөлім ауыстыру.
- lib/widgets/ — мәзір, логотип, шаралар тізімі, толық ақпарат, қатысу есебі және анықтамалық.
- test/ — рөл, өтінім, лимит, сақтау және экран тесттері.

## Деректер мен шектеулер


Бұл — бір құрылғыға арналған функционалды прототип. SQLite ішінде аккаунттар, шаралар, өтінімдер, хабарламалар және сақталғандар сақталады. SharedPreferences бұрынғы деректерді бір рет көшіру үшін қолданылады. Құпиясөз ашық мәтін ретінде сақталмайды (жеке salt + SHA-256), бірақ бұл тәсіл өндірістік пароль сақтау стандартының орнына жүрмейді. Аккаунт сеансы қайта іске қосқанда ашылмайды.

Демо әкімшінің деректері ашық. Құрылғы иесі жергілікті сақтау орнын өзгерте алады. Нақты жариялау алдында сервердегі авторизация, сенімді пароль хэштеу, серверлік рөл тексеру, ортақ серверлік деректер базасы және құрылғылар арасындағы синхрондау қажет. SQLite файлы шифрланбаған.

Өтінім нақты медициналық ұйымға жіберілмейді; төлем, медициналық қабылдауды брондау немесе push-хабарлама қызметі қосылмаған. Билет — тек осы прототип ішіндегі қатысу коды. Қатысу есебі ресми құжат емес.

Кэш немесе қолданба деректері тазаланса, жергілікті ақпарат жойылады. Сақтау қатесі интерфейсте көрсетіледі.

## Іске қосылу және жеке кабинетке кіру

Алдымен ÜMIT логотипі бар Splash экран көрсетіледі. Ол жергілікті деректердің жүктелуін күтеді және кемінде 1,2 секундтан кейін авторизацияға ауысады. Splash коды: lib/screens/splash/splash_screen.dart.

Қонақ жалпы бөлімдерді қарай алады. Жеке кабинетке мәзір, төменгі навигация немесе профиль батырмасы арқылы өту үшін авторизация қажет. Кіруден кейін сұралған жеке кабинет ашылады. Жүйеден шығу сеансты аяқтап, навигация тарихын тазартады; артқа қайту арқылы жеке деректерге қол жеткізу мүмкін емес.

Тексеру: test/splash_access_test.dart — жүктелуді күту, Splash жабылғаннан кейінгі кеш аяқталу, қонақтың кіру нүктелері, авторизациядан кабинетке оралу және шығу қорғанысы.

## SQLite және кестелерді қарау

База атауы — `umit.db`. Қосымша оны автоматты құрады; PostgreSQL, Node.js сервері және `.env` қажет емес.

Кестелерді қарау: демо әкімшімен кіріңіз → «Деректер базасын кесте түрінде ашу». Пайдаланушылар, іс-шаралар, өтінімдер, хабарламалар және сақталған шаралар жеке кесте ретінде көрсетіледі. «Жаңарту» батырмасы сақталған деректерді қайта оқиды. Бұл бөлім тек әкімшіге қолжетімді.

Базаны бөлек ашу: кестелер экранында «Базаны жүктеу (.db)» батырмасын басыңыз. Браузер `umit.db` файлын жүктейді. Файлды VS Code-та SQLite Viewer немесе DB Browser for SQLite арқылы ашуға болады. Мобильді/компьютер нұсқасында көшірме Documents каталогына сақталады. Экспорт барлық 10 кестені, деректерді және құпиясөз хэштерін қамтиды; кейінгі өзгерістер үшін файлды қайта жүктеңіз. Жүктелген көшірмені өзгерту қосымшадағы базаға әсер етпейді.

Android/iOS/macOS-та sqflite, Windows/Linux-та sqflite_common_ffi, браузерде sqflite_common_ffi_web қолданылады. Windows/Linux-та файл қолданбаның support каталогында, вебте браузердің осы сайтқа арналған сақтау орнында болады. Браузердің IndexedDB панелі SQL кестелерін тікелей көрсетпейді; қосымшадағы кесте экранын пайдаланыңыз.

Базада 10 қолданбалық кесте бар: accounts, events, requests, notices, saved, metadata, categories, locations, articles және article_sections. Соңғы төрт кесте шара санаттарын, өткізу орындарын, ақпараттық мақалалар мен олардың бөлімдерін сақтайды. Санаттар мен орындар іс-шаралардан жаңартылады; мақалалар қосымшаның анықтамалық материалдарынан толтырылады. SQLite нұсқасы 2: бұрынғы база автоматты жаңартылады, аккаунттар мен өтінімдер сақталады. Барлық 10 кесте әкімші экранында көрсетіледі.

Өзгерістер транзакциямен жазылады. Сыртқы кілттер өтінімдер, хабарламалар және мақала бөлімдерінің байланысын тексереді. Бұрынғы SharedPreferences деректері бос базаға көшіріледі; ескі жазба SQLite-қа сәтті сақталғаннан кейін ғана жойылады. Құрылғылар арасында синхрондау жоқ.

Құпиясөздер жеке кездейсоқ salt + SHA-256 хэшімен жазылады. SQLite файлы шифрланбаған; аккаунттар арасында автоматты кіру сақталмайды.

Веб-жариялауда `web/sqlite3.wasm` және `web/sqflite_sw.js` файлдарын бірге орналастырыңыз. Пакет жаңартылғанда файлдарды қайта дайындау: `dart run sqflite_common_ffi_web:setup --force`. HTTPS немесе localhost пайдаланыңыз. Браузер сақтау орны тазаланса, жергілікті база да жойылады.
